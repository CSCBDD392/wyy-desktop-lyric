# 网易云桌面歌词 · wyy-desktop-lyric

在网易云音乐网页版放歌，**桌面上挂一条跟着滚动的歌词**。浏览器最小化、被别的窗口挡住都照常显示。

```
● 歌名  歌手
        当前唱到的那一句（大字）
        下一句 / 翻译 / 罗马音
────────────────── 1:43 / 5:26
```

## 两套东西，按需选

| 目录 | 是什么 | 要不要装 |
| --- | --- | --- |
| [`desktop/`](desktop/) | **桌面歌词条**：读取 Windows 系统媒体会话，浏览器最小化也能看 | 双击 `启动.cmd` 即可 |
| [`extension/`](extension/) | 网页版悬浮歌词面板（Edge/Chrome 扩展） | 可选，装了才需要 |

**推荐用 `desktop/`**，它不依赖浏览器扩展，任何会向系统上报媒体的播放器都能用
（网页版 Edge / Chrome、网易云客户端都行）。

## 快速开始

```
克隆/下载本仓库
  └─ desktop\
       ├─ 启动.cmd          ← 双击这个
       ├─ server.js
       ├─ smtc-bridge.ps1
       └─ DesktopLyric.exe
```

然后在你惯用的播放器里放歌就行。详细说明见 [`desktop/README.md`](desktop/README.md)。

## 环境要求

- Windows 10 / 11（或 Windows Server 有桌面体验）
- Node.js（`启动.cmd` 会优先用随附的运行时，其次找系统 `node`）
- 无需管理员权限，无需联网（取歌词时才联网）

## 技术要点

这个项目里比较有意思的两处坑，写在代码注释里了：

**1. 系统媒体会话的位置是"冻住"的**

Windows 的媒体会话（音量键弹出的那个卡片）能给出歌名/歌手/播放状态/位置，
但**连续播放时位置和更新时间都不刷新**，只在暂停、恢复、切歌、拖动时才刷一次。

所以做的是「锚定 + 外推」：记住某次刷新的位置和时刻，播放中按流逝时间往前推；
只在锚点真的变化时重新锚定。细节在 [`desktop/smtc-bridge.ps1`](desktop/smtc-bridge.ps1)。

**2. 置顶窗口不能指望 Chromium**

试过用 Edge 的 `--app` 窗口套壳，`SetWindowPos(HWND_TOPMOST)` 返回成功但 Chromium 窗口不认这个标志，
最大化别的窗口后字幕就被盖住。最终改成自绘的原生 WinForms 分层窗口。
实现在 [`desktop/src/DesktopLyric.cs`](desktop/src/DesktopLyric.cs)。

**3. 版权行不是歌词**

网易云的 LRC 末尾常塞着 `录音 : xxx`、`OP : xxx`、`SP : xxx` 这些版权信息，官方网页版不显示。
服务端会把末尾这段整段剔除，中间的标记为 `credit` 且不抢高亮。

## 已验证

- 媒体会话读取与位置外推：3 秒采样收到 +3.02 秒，不回跳
- 暂停 / 恢复时锚点随 SMTC 刷新正确更新
- 歌名 → 歌曲 id 匹配、歌词取回（晴天 62 行、海阔天空 42 行含粤拼、富士山下 65 行、起风了 71 行、孤勇者 79 行）
- 置顶：最大化其他窗口后歌词条仍在其上方
- 全局热键：`Ctrl+Alt+L` 显隐、`Ctrl+Alt+C` 单行/双行、`Ctrl+Alt+Q` 退出
- 断连 5 分钟自动收起，重新播放自动恢复

## 已知限制

- 纯靠系统媒体会话时，位置精度取决于播放器上报的频率；拖动进度条后最多有几秒的偏差，下一次刷新即校正
- 有浏览器扩展时用扩展的精确歌曲 id，能避免"按歌名搜 id"偶尔搜错
- 只支持 Windows
