# 网易云歌词面板（Edge 扩展）

给 **music.163.com 网页版** 播放器加一个清爽的悬浮歌词面板：歌词从网页接口在线抓取，
跟着播放进度滚动，支持翻译和罗马音，不影响站点原有 UI。

> **想要浏览器最小化后也能在桌面看歌词？**
> 这个扩展还能把播放状态推给同目录外的 `wyy-desktop`（桌面歌词条）：
> 弹窗里打开「推到桌面歌词条」即可，桌面端双击 `..\wyy-desktop\启动.cmd`。
> 详见 `..\wyy-desktop\README.md`。

```
wyy-lyric/
├─ manifest.json     扩展清单（MV3）
├─ content.js        隔离世界脚本：取词 + LRC 解析 + 设置存储
├─ main.js           主世界脚本：探测播放状态 + 绘制面板
├─ panel.css         面板全部样式（wyy- 前缀，不污染站点）
├─ background.js     服务工作线程：跨域取词的唯一出口（白名单）
├─ popup.html/js     点扩展图标弹出的设置面板
└─ icons/            16/32/48/128 图标
```

## 装到浏览器上（30 秒）

Edge 155 / Chrome 111 以上都行，本机是 Edge。

1. 地址栏输入 `edge://extensions/` 回车
2. 打开左下角（或左侧栏）的 **开发人员模式**
3. 点 **加载解压缩的扩展**，选中本文件夹：
   `C:\Users\Administrator\Documents\deepseek-harness\default-workspace\wyy-lyric`
4. 打开或刷新 `https://music.163.com`，右上角就会出现歌词面板

> 不需要登录、不需要装油猴、不需要科学上网。装好后如果页面已经开着，按 F5 刷一下即可。
> 想固定到工具栏，点地址栏右边的拼图图标 → 把「网易云歌词面板」眼睛图标点亮。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 播放任意歌曲 | 面板自动加载当前歌曲歌词并跟随滚动 |
| 点某一句歌词 | 跳到那一句（可在弹窗里关掉） |
| 拖标题栏 | 移动面板；小窗模式下拖整块 |
| `Alt` + `L` | 显示 / 隐藏面板 |
| `Alt` + `C` | 展开态 ↔ 小窗态（只显示当前一句，贴右下角） |
| 底部「译」/「音」 | 切换翻译 / 罗马音；那首歌没有对应内容时按钮是灰的 |
| `↻` | 重新抓一次歌词（切歌后歌词不对时用） |
| `–` / `×` | 切小窗 / 隐藏面板 |
| 点扩展图标 | 调字号、透明度、歌词来源、开关功能，并能「测试取词」 |
| 弹窗「推到桌面歌词条」 | 把歌名/进度上报给本地服务，供桌面歌词窗使用 |

面板位置、显示状态、字号这些设置存在扩展自己的 `chrome.storage.local` 里，换标签页也在。

## 桌面歌词（浏览器最小化也能看）

扩展每 1 秒把「歌名 / 歌手 / 播放位置」POST 给 `http://127.0.0.1:28123`，
桌面端按墙钟推算实时位置并绘制置顶歌词条。所以：

- 标签页被浏览器节流（最小化后计时器会变慢）也不影响，歌词不会卡住
- 上报请求走扩展的后台线程——HTTPS 页面直接 POST 到 127.0.0.1 会被 Chromium 的
  「本地网络访问」策略拦掉，走后台才通

开关和端口在扩展弹窗的「桌面歌词」一节，能直接看到服务连没连上。

## 歌词从哪来

两条链路，首选官方：

1. **网易云官方网页接口** `music.163.com/api/song/lyric`（免登录、免 cookie）
   - 一次请求同时拿原文 `lrc`、翻译 `tlyric`、罗马音/粤拼 `romalrc`
   - 就是网页版自己用的那份数据
2. **QQ 音乐接口**（兜底）`c.y.qq.com`，只在官方接口报错或没有歌词时启用，可在弹窗里手动固定为它

请求都放在 `background.js` 里发（带 `host_permissions`，不受网页 CORS 限制），并且：

- 只允许上面白名单里的地址，只发 GET
- 不带 cookie、不带 `credentials`，不碰你的账号信息
- 不读页面上的任何 DOM 内容上传，只把「歌曲 ID / 歌名」发出去取词

## 实现上值得说几句

- **为什么有主世界脚本**：网页版把播放状态挂在页面自己的对象上（`window.player.getPlaying()`），
  隔离世界读不到，所以 `main.js` 用 `world: "MAIN"` 注入，读状态、画面板。
- **为什么要 background 取词**：网易接口只回 `Access-Control-Allow-Origin: https://music.163.com`，
  网页里跨域 fetch 会被拦；扩展带 host 权限的请求不受此限。
- **取歌 ID 有四层兜底**：`getPlaying().track` → 播放器实例嗅探 → 播放条 `.words` 上的歌名
  → 用歌名搜 ID（会做歌名比对，对不上就不用，宁可不显示也不张冠李戴）。
- **进度**：读播放条上的 `00:12 / 04:29` 文本，200ms 一次，不碰音频元素，切歌/暂停都稳。
- **制作信息处理**：网易把「作词/作曲/编曲」塞在 0~20 秒的连续时间戳里，面板会把它识别为
  非歌词行、压成瞬时显示，不会挡住第一句歌词。
- **状态同步双通道**：事件（即时）+ 面板 `data-wyy-state` 属性（兜底轮询），
  避免浏览器版本差异导致事件跨世界丢包。

## 排障

**面板没出现**
1. `edge://extensions/` 里确认扩展是「已启用」，没有红色错误
2. 在 `music.163.com` 页面按 F5（装扩展前打开的标签页不会自动注入）
3. 按 `Alt` + `L` 试试——有可能只是被隐藏过

**有面板但一直没歌词**
1. 点扩展图标 →「测试取词」，看返回的是行数还是报错
2. 报「当前标签页不是网易云音乐」→ 说明开错了页面
3. 报网络错误 → 确认本机能打开 `music.163.com`（这台服务器实测可达）
4. 下载类/本地文件播放的歌本来就没歌词，面板会显示「这首歌还没有歌词」

**歌词和歌名对不上**
点面板标题栏的 `↻` 重新获取。若仍不对，多半是「歌名搜 ID」在特殊页面上匹配错了，
把当前页面地址和歌名记下来即可定位。

**想看调试信息**：在网易云页面按 F12，控制台执行

```js
window.__WYY_DEBUG__ = true;          // 打开日志
window.__WYY_LYRIC_API__.status();    // 当前歌曲/探测方式/歌词行数/最近日志
window.__WYY_LYRIC_API__.refresh();   // 重新取词
```

## 改了代码怎么生效

扩展的文件不是热更新的：

1. `edge://extensions/` 里点本扩展卡片上的 **重新加载**（🔄）
2. 回到 `music.163.com` 按 F5

## 已验证过的场景

在无头 Edge 155 里实机跑过（headless 无法真正出声，播放态用扩展自带的调试钩子接管）：

- 面板注入、设置下发、`document_start` 阶段不崩
- 真实取词：晴天 62 行（含翻译徽标）、海阔天空 49 行（粤拼 35 行）、
  平戸慕情（日语罗马音 15 行）、I Wanna Get Better（翻译 91 行）
- 跟随滚动：高亮行随时间前进并居中
- 小窗模式：434×74，贴右下角并避让播放条，只显示当前一句
- 空歌词：居中提示 + 「重新获取」按钮
- 隐藏/显示、字号/透明度、来源切换、按钮按可用性置灰

解析器另外用真实接口数据做过离线校验：非法时间戳 0 个、乱序 0 处、
制作信息识别正确。
